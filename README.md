# Campus Vault

A student notes sharing platform built using React, Firebase, and Google Drive.

## 🌐 Live Demo
🔗 https://campus-vault-5debf.web.app

## 🚀 Features
- User authentication (Firebase)
- Upload notes via Google Drive links
- Search & filters
- Real-time updates

## 🛠️ Tech Stack
- React (Vite)
- Firebase Authentication
- Firestore Database
- Google Drive
- Firebase Hosting
